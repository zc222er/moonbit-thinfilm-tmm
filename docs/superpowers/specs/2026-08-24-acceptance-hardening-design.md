# MoonBit 薄膜 TMM 验收加固设计

## 目标

把现有 MoonBit 薄膜光学库整理为可复现、可测试、可持续集成的验收版本：保持申报书只读，保留真实有效的生产源码规模，补足边界测试和可重复基准，并让 README 与实际命令输出一致。

## 方案

1. 在现有 `cmd` 体系中增加 benchmark 模式，使用固定的 2×2 多层谱、4×4 各向异性层和器件级谱场景。基准代码只调用公开库 API；耗时通过命令行计时得到，README 只记录本地实测结果和环境，不作未经测量的性能承诺。
2. 为核心数值边界补充黑盒测试，优先覆盖空/单层堆栈、光谱边界插值、无效网格、吸收介质能量收支、各向同性 4×4 退化和优化器有界结果。先写失败测试，再写最小实现或修复。
3. 将弃用的隐式 trait 方法调用改为显式 trait 调用，使测试也能在 `--deny-warn` 下运行。
4. 参照 MoonBit 社区 workflow 模板，把 CI 扩展为三平台矩阵和全目标检查；保留现有 `ci.yml` 文件名以避免 README badge 失效。
5. 重写 README 的信息架构和数字，只保留可由本地命令验证的功能、测试、源码规模和基准数据；不在 README 加入申报书处理、贡献者身份或结项内部说明。`项目申报书.md` 不修改。

## 验收证据

- `moon version --all` 显示 MoonBit 编译器版本不低于 v0.10.9。
- `moon fmt --check`、`moon check --deny-warn --target all`、`moon test --deny-warn --target all`、`moon info` 均成功，且生成接口无未提交差异。
- benchmark 命令成功输出固定场景结果，外部脚本可重复采样并输出中位耗时。
- Git 工作区只包含本次整改的预期文件，申报书内容哈希保持不变。
